# Changelog

## 0.1.0

- Native Rust counterpart of the owned Go banner renderer, localization,
  structured build metadata, completion output and credential-safe display API.
- Strict catalogs and immutable per-call configuration; no runtime metadata discovery.
- Go-produced compatibility vectors and failure, concurrency, environment and
  package checks on Rust 1.99.1 x86_64-pc-windows-msvc.

The Cargo coordinate is separate from the repository's full release identity.
Git integration, mirror publication and final release evidence belong to issue #1.
